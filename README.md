# 《星盾防线 / Star Shield》游玩指南（V1.0）

> **一句话**：真实引力物理防守游戏——你不能用武器，只能摆放**有质量的真实星体**（小行星 / 恒星 / 黑洞），用万有引力把来袭陨石**引偏、撞毁或收编**，守护中心母星。核心玩法：改变引力场，让威胁自己拐弯。

---

## 0. 如何运行（极简）

- **双击 `index.html`** 即可游玩。纯前端、零依赖、无后端、全程离线。
- 预测与音效均在浏览器内同步计算，无需任何服务器或安装。
- 点击右侧档位按钮选星体，在画面空白处**拖拽**摆放；点「暂停」可冻结时间从容布防。

---

## 1. 游戏简介

- **类型**：真实引力物理防守游戏（全 N 体模拟 + 塔防思路）。
- **目标**：你不能用武器。只能摆放有质量的真实星体，用万有引力把来袭陨石引偏、撞毁或收编，守护中心母星。
- **核心反直觉**：你唯一的能力是「改变引力场」。

---

## 2. 核心机制（规则 + 反馈）

```
陨石从四周来袭（走真实引力轨道）
→ 你拖拽摆放星体，系统实时画出它未来 5 秒的预测轨迹
→ 陨石被引偏(保母星) / 被你的星体撞毁(清场) / 被黑洞吞噬(得分) / 安全飞出边界(少量分)
→ 母星受击扣血 / 屏震反馈 / 结算 = 得分 − 已花费
```

---

## 3. 你该懂的真实物理（不用算，看现象）

- 所有天体互相吸引，**你放的星体也会被拉走、会自己动**（不是钉子）。
- 陨石走真实椭圆 / 双曲线轨道：离母星近就快、远就慢。
- 你的星体与陨石**物理接触会双双炸毁**（撞击防守，也是清场手段；但放歪会伤到自己的星体）。
- 想让星体长期绕母星当防线？给它合适的初速就能稳定转圈（游戏里靠预测线帮你瞄）。

---

## 4. 你的工具：星体五档

| 类型 | 质量 | 花费 | 主要玩法 |
|---|---|---|---|
| 小行星 | m=50 | 3 点 | 撞击为主：便宜，可成排拦截 |
| 中行星 | m=200 | 6 点 | 撞击为主，略带引力 |
| 大行星 | m=600 | 12 点 | 撞击 + 引力（质量大，撞击清场强） |
| 恒星 | m=1500 | 20 点 | 撞击 + 强引力（大范围控制） |
| 黑洞 | m=6000 | 30 点 | 纯引力·静止·限时 12 秒：明显弯曲所有非母星轨道并吞噬撞来的天体（双刃：伤友方） |

**不限制建造总数**：放置时只把花费累加到「已花费」，结算时按总花费从最终得分里扣除。因此要在「用最少的钱守住母星」和「堆强力设施」之间权衡。

> ⚠️ **黑洞禁放区**：黑洞不可放在母星周围（禁放半径 = 母星半径 + 黑洞半径 + 60px）。在禁放区内松开鼠标会被拒绝，且不扣费——超大质量会剧烈扰动母星周边轨道，且静止不可移动无法补救。普通星体不受此限（你可以在母星旁近距离布防）。拖拽黑洞时会实时显示**红色禁放圈**，所见即所得。

---

## 5. 核心操作：拖拽绘图法

**三步放置**
1. **按压**：在空白处按住左键，出现一个半透明「虚影星体」跟着鼠标。
2. **拖拽**：移动鼠标，系统每秒刷新约 30 次预测线。拖拽方向 = 初速方向，拖拽长度 = 初速大小（1 像素 = 0.5 m/s，白箭头实时显示）。预测线从虚影出发，模拟它未来 5 秒怎么飞。
3. **释放**：松开鼠标，虚影实体化，按预测线最后的状态注入物理引擎，正式加入 N 体模拟。

**预测线三色警示（必读技巧）**
预测线按轨迹终点是否撞上天体自动变色，帮你决策：

- 🟢 **绿色**：预测轨迹将被某黑洞吞噬 → 这是得分机会，放手！
- 🔴 **红色**：预测轨迹将撞上母星或被其它星体阻挡 → 危险 / 受阻，别放！
- 🔵 **蓝色**：安全，或形成「引力弹弓」把陨石甩走。

线型为虚线（近粗远细，有透视感），让距离一目了然；轨迹在撞上任意天体的地方**自动截断**，绝不会画出「穿过天体仍判可通行」的幽灵路径。

**两种模式**
- **简易模式（默认）**：预测线强制常亮，使用蓝 / 红 / 绿三色，但不显示数字，新手友好。
- **专业模式**：可关闭预测线；适合闭眼也能摆的高手。

**高手精确输入**：专业面板里可填 `vx, vy` 数字，系统会反向画出对应静态预测线供校验（默认折叠，不干扰新手）。

---

## 6. 暂停布置（策略核心）

随时点**暂停**，时间冻结，你从容拖拽摆放星体、看预测线规划布局；点**继续**，物理从当前状态继续演化。危机时暂停思考，是高手保命诀窍。

---

## 7. 得分与反馈（明确规则）

每成功化解一颗陨石即得**固定基础分**（不再叠加连击，避免分数爆炸）：

- **撞击炸毁**（陨石与你的星体相撞爆炸）：**+25**
- **黑洞吞噬**（陨石撞入黑洞）：固定 **+20**
- **安全飞出边界**（陨石未撞母星、自然飞出画面）：固定 **+8**
- 任意天体撞上母星：母星 **−12 血**、屏震
- 结算：最终得分 = 累计得分 − 已花费（建得越多扣得越多）

三种化解各有专属动画做反馈：**撞毁 = 橙红爆炸**、**吸入 = 紫色漩涡**、**飞出边界 = 青蓝淡出**。

**HUD**：分数 / 波次 / 已花费 / **最高分**（本地记录）/ **撞毁**（撞击数）/ **吸入**（黑洞吞噬数）/ 母星血量。化解陨石时画面弹出彩色**飘字（+分数 / −血量）**。黑洞上方实时显示剩余寿命（倒计时环 + 秒数）。

**音效**（`js/audio.js`，纯 Web Audio 合成）：放置 / 撞毁 / 吸入 / 撞母星 / 飞出 五种，首次鼠标交互自动解锁，无音频环境静默降级。

**战绩本地存**：`localStorage` 记录最高分，结算破纪录显示「★ 新纪录！」。

## 8. 特殊天体

- **黑洞**：静止 · 超大质量 · **限时 12 秒**（到期坍缩消失，吸入式漩涡动画）。纯靠引力弯曲轨道，并吞噬一切撞来的天体（包括陨石与你的其它星体，双刃：伤友方）。因限时且最贵，单次放置收益有限，需权衡频繁重建的花费。注意：黑洞不能放在母星禁放区内（见第 4 节）。
- **恒星 / 小行星**：常规引力体，质量差异定战术。

---

## 9. 可玩性 & 真实平衡

- 底层 100% 真公式；表层用**预测线三色**把物理「翻译」成直觉（蓝安全 / 红危险 / 绿得分）。
- 新手靠预测线盲摆也能玩；高手关掉线、填数字、算轨道，玩出真实物理深度。

## 10. 技术实现（给想看代码的同学）

- **物理引擎** `js/physics.js`：万有引力 + 全 N 体 + 动量合并 + 暂停演化（Verlet 辛积分）。星体半径 `r ∝ mass^(1/3)`，黑洞静止不可动。
- **轨迹预测** `js/predictor.js`：用「整系统前向 N 体模拟」（`simulateFuture`，与真实积分 `stepSystem` 完全一致，预测线与放置后实际轨迹严格吻合）。内部细步长 `PREDICT_DT=0.05s` 积分、预测 5 秒、零依赖同步计算；`evaluateRisk` 用「线段-圆整段检测」在轨迹撞上任意天体（阈值 = 两球半径之和）处**截断轨迹并定色**，不会出现幽灵路径。
- **抗闪烁**：提示线每帧对轨迹点做指数插值缓冲，拖拽线对鼠标坐标做去抖滤波，从根上消除「预测线乱跳 / 闪烁」。
- **渲染** `js/render.js` + `js/predictorRenderer.js`：Canvas 拖尾 + 速度着色 + HUD + 三色预测虚线 + 飘字 + 黑洞禁放圈。
- **交互** `js/input.js`：拖拽绘图法三阶段（按压 → 移动 30Hz 刷预测线 → 松开实体化）、质量档 + 预算、暂停、简易 / 专业模式、精确输入面板。
- **音效** `js/audio.js`：纯 Web Audio 合成，零依赖，首次交互解锁。
- **入口** `index.html`：按 `physics → predictor → render → predictorRenderer → audio → game → input` 顺序加载。

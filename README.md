# 星盾防线 / Star Shield（v1.14）

真实引力物理防守游戏：不能用武器，只能摆放**有质量的真实星体**，用万有引力把来袭陨石**引偏、撞毁或收编**，守护中心母星。

> 各版本更新内容见 [Releases](../../releases) 与 git 提交记录。

## 运行

- 双击 `index.html` 即可游玩：纯前端、零依赖、全程离线（无构建步骤）。
- 开发：`npm test` 跑「语法检查 + 全部测试套件」（零依赖，Node ≥ 18）。
- **纯单机**：无账号、无云存档、无排行榜，不发起任何网络请求；全部进度只存本机 `localStorage`（键名前缀 `starshield_`），「清除进度」会一并删除。

## 模式

- **生存**：无限星能、限时来袭，比拼累计分数。
- **无尽**：无限波次，比拼最高波数。难度 **10 波一个阶段**递进，每阶段收尾波（第 10 / 20 / 30… 波）为**风暴波**（额外涌入一群分裂彗星）；HUD 显示「第 N 波 · 阶段 M · 距风暴 X 波」，风暴波整条转红。
- **闯关**：固定星能，**40 关分 4 章**层层递进（波数、来袭速度与质量逐关上升），通关解锁下一关，**第四章另需累计 40 星**。每关 1~3 星：★1 通关、★2 受击不超过阈值、★3 零受击，满星 120。
- **隐藏关**（2 关，不计星）：「无声围城」（星能减半 + 禁道具）与「双倍绝境」（来袭 ×1.5 + 禁黑洞 + 禁回收升级）；解锁条件为**累计 100 星**与**40 个常规关任务全清**。各有专属结语，第二关为真结局。
- **挑战**：同样 40 关，按关卡序号**确定性挂载递增修饰符**（禁道具 → 来袭加速 → 星能减半 → 禁黑洞 → 禁回收升级，每 6 关 +1 条、上限 5 条），修饰符全部真实生效；进度与挑战星独立。
- **每日**：由本机日期派生种子的固定关卡，波次、强度、星域、修饰符（含「禁减速」）与任务每天一变；记录当日最高分与**连续通关天数**，跨日自动刷新。
- **关卡目标与结算**：开局横幅显示本关目标、额外任务与失败条件（章首关附剧情文案）；HUD 常驻当前进度与下一波预告；结算面板展示任务结果、最佳纪录对比、结局文案（仅闯关第 40 关与隐藏关），胜利时提供「下一关」（仅在确实存在下一关时显示）。
- **每局从零开始**：开局场上只有母星，所有星体由你自行摆放。

## 操作

- **放置**：在下方星体栏选档位，再点击空白处摆放（成本 = 质量；星能不足或离母星太近会提示）。场上星体上限 **60**。
- **轨迹线**（未来 6 秒、每 2 秒一段共三段，可分别开关）：拖拽时显示**预测线**，场上运动天体显示**提示线**；🔵 安全 / 🔴 将撞母星 / 🟢 将被黑洞吞噬。
- **慢动作**：每局 **15 秒**额度，按真实时间消耗，每清空一波返还 3 秒（封顶 15 秒），耗尽自动恢复常速；**每局开局复位为常速**。
- **暂停**：按 `P` 暂停 / 继续，或在底部控制条点「暂停」；暂停层内可直接继续、重新开始、返回菜单或进入设置。`Esc` 在有选中星体或已选道具时**优先取消**，否则同样用于暂停。暂停期间物理、计时、减速额度与黑洞寿命**全部冻结**，结算时自动解除。
- **撞母星预警**：对未来 6 秒内将撞击母星的威胁显示红色光环与倒计时，可用「预警」开关关闭。
- **撤销**：点击「撤销」或按 `Z`，撤销**最近一次、5 秒内且仍在场上**的放置并全额返还星能。
- **回收 / 升级**：点击场上星体选中，可「升级」升一档（补差价，黑洞不可升级）或「回收」返还成本 **70%**；`Esc` 取消选中。
- **道具**（纯引力 / 空间机制，无武器）：引力脉冲（临时强引力井）、斥力波（推离母星）、凝滞（减速且不消耗额度）。闯关 / 挑战 / 每日按关卡发放固定配额，生存与无尽开局各 1 个、之后每清 5 波补 1 个（单个上限 3）；选中后点击画布释放，`Esc` 取消。
- 其他：来袭威胁被引力长期拘禁时，单波超过 40 秒判定「已被引力收编」并清场；任何星体触碰屏幕边界即消失。

## 星体与专精

| 档位 | 成本 | 玩法 |
|---|---|---|
| 小行星 | 50 | 弱引力，微调轨道 |
| 中行星 | 150 | 中等引力，批量布防 |
| 大行星 | 300 | 主力控场，明显引偏来袭天体 |
| 恒星 | 500 | 强引力，大范围捕获 |
| 黑洞 | 1500 | 吞噬一切撞来天体，10 秒后自动消失（母星旁禁放） |

- **专精**：同一档位可选**引力型**（默认，质量 / 半径 / 价格 ×1.00）或**巨型**（质量 ×0.80、碰撞面 ×1.50、价格 ×1.20）；放置与升级沿用当前专精，已放置星体可同档互转，星体栏价格实时同步。黑洞不参与专精。
- **布局协同**：相距 150px 内的玩家星体彼此 **+5%** 引力（互邻上限 **+30%**）；靠近场景机关（120px 内）再 **+10%**，总上限 **+40%**。加成在物理积分器内结算，预测线与实战一致。
- **场景机关**：部分星域自带真实机关（伴星 / 引力井 / 固定障碍 / 脉冲源），只参与引力与碰撞，不可点选、回收或升级。
- **母星**：固定天体，血量随关卡递减，归零即失败；**只有来袭威胁会造成伤害**。
- **Boss**：每 5 关的收尾波出现多段巨型天体（3~5 段），被撞击或被吞噬逐段摧毁，撞上母星扣 2 点血。
- **威胁类型**：陨石、彗星，以及**分裂彗星**（被清除时裂成 2 个子体）与**引力干扰体**（周期性推挤附近天体）。

## 得分 / 成就 / 进度

- **得分**：清掉威胁按「类型 × 难度 × 关卡倍率」加分，清波另有奖励，母星受击扣分；分数一律为整数。挑战与每日不计关卡倍率。
- **成就 26 项**：覆盖通关与星级、操作、经济、星体专精、布局协同、每日挑战、隐藏关、任务全清、无尽风暴与完美收集。解锁时在结算面板提示，菜单可展开查看进度，重复达成不重复提示。
- **额外任务（只判不罚）**：每关一条确定性附加目标（如不使用道具 / 不减速 / 零受击 / 星能结余达标），达成只留金标记，**不改变星级与关卡难度**。
- **星图总览**（菜单可展开）：收集进度（星数分布 / 任务 / 隐藏关 / 挑战 / 每日连胜 / 成就）、统计摘要（累计时长、拦截、受击、各模式场次与胜率、历史最高分与最高波数）；收集度 100% 时显示「完美星图」。
- **每关最佳记录**：各模式每一关记录**最佳分数 / 最少受击 / 最快通关用时**，只择优不回退。
- **设置与界面**：主菜单与暂停层共用同一个「设置」面板（预测线 / 撞母星预警 / 音效 / 主音量滑条 / 减少动效），改动实时生效并保存在本机；界面为深空玻璃拟态风格，统一配色、内联 SVG 图标与等宽数字，并自适应超宽屏 / 桌面 / 平板 / 手机与横屏。选择「减少动效」会关闭过渡与脉冲动画（也自动遵循系统的 `prefers-reduced-motion`）。

## 源码结构

纯前端、零构建、零依赖：经典 `<script>` 按依赖顺序加载（**不使用 ES Modules**，确保 `file://` 双击 `index.html` 即可运行）。

- **物理与渲染**：`js/physics.js`（万有引力 N 体与碰撞）、`js/predictor.js` + `js/predictorRenderer.js`（前向预测与风险判定，与实战共用同一物理内核）、`js/render.js`（Canvas 绘制）、`js/audio.js`（Web Audio 程序化音效）、`js/levels-campaign.js`（确定性关卡数据）。
- **游戏层**（内部命名空间 `window.SS`，加载顺序即依赖顺序）：`core`（常量 / 全局状态 / 工具）→ `persist`（存档键 / 设置 / 星级）→ `achievements` / `challenge` / `records` / `daily`（成就 / 挑战 / 记录统计 / 每日）→ `progress`（解锁 / 计分 / 隐藏关）→ `waves`（波次生成与特效）→ `world`（关卡初始化 / 星体操作）→ `flow`（主循环 / 结算 / 开局）→ `js/game.js`（聚合对外 API `window.game` + 启动调用）。
- **界面层**（内部命名空间 `window.SSUI`）：`js/ui/menu.js`、`hud.js`、`panels.js`、`result.js` 与 `js/input.js`（指针 / 键盘 / 主循环装配）。
- **样式**：`css/` 按 `tokens → components → screens → overlays → menu → panels → motion → responsive` 分层导入。
- **测试**：`test/*.test.js`（21 套）；`test/helpers/sandbox.js` 集中维护被测文件清单、`test/helpers/css.js` 集中维护样式分层清单，拆分文件时只需改这两处。

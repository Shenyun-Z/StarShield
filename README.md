# 星盾防线 / Star Shield（v1.11）

真实引力物理防守游戏：不能用武器，只能摆放**有质量的真实星体**，用万有引力把来袭陨石**引偏、撞毁或收编**，守护中心母星。

> 版本更新内容见 [Releases](../../releases) 与 git 提交记录。

## 运行

双击 `index.html` 即可游玩。纯前端、零依赖、全程离线。

开发：`npm test` 运行「语法检查 + 全部测试套件」（零依赖，仅需 Node ≥ 18）。

> **纯单机**：无账号、无云存档、无在线排行榜，也不发起任何网络请求。全部进度（战绩、解锁、星级、挑战进度、每日成绩与连胜、额外任务、最佳记录、成就、累计统计与历史榜单、设置）只保存在本机 `localStorage`（键名前缀 `starshield_`），「清除进度」会一并删除。

## 模式

开局菜单选择：

- **生存模式**：无限星能、限时来袭，比拼**累计分数**（活得越久、清得越多分越高）。波次仅用于内部难度递增，不计入成绩。
- **无尽模式**：无限波次、无时间限制，比拼**最高波数**（同时记录累计分数）。本机记录显示为「无尽最高 N 波」。
  - **阶段与风暴（v1.11）**：难度按 **10 波一个阶段**推进（阶段 1 = 第 1~10 波，阶段 2 = 第 11~20 波……），每个阶段的强度阶梯高于上一阶段（来袭更快更密、彗星占比更高、特殊威胁开始混入），**每个阶段的收尾波（第 10 / 20 / 30… 波）是「风暴波」**：额外涌入一群分裂彗星，构成明显暴增。
  - HUD 常驻显示当前波数与阶段进度（「第 N 波 · 阶段 M · 距风暴 X 波」；无尽模式的波次只在此处显示），风暴波整条转红并呼吸提示，进入风暴时还有文字提示（「风暴来袭 · 第 N 波」）。
  - 第 1~10 波与上一发布版（v1.10）完全一致（阶段 1 无任何加成），之后**难度随波次单调不减**；阶段参数在最后一段（第 51 波起）封顶，避免无限膨胀。
- **闯关模式**：固定星能、**40 关层层递进**（前三章 30 关 + 第四章 10 关，另加 2 个隐藏关单独列出），比拼**通关进度**。母星血量随关卡递减、星能收紧、波次增多、来袭速度与质量提升、彗星占比上升。每关关卡卡片均展示**简介**（场景特色与挑战）。
  - **章节结构**：40 个常规关分为 4 章（第一章 星域初探 / 第二章 引力深井 / 第三章 风暴核心 / 第四章 星海终局），菜单按章分组并显示该章星数完成度；每章首关的开局横幅会先显示一句**剧情文案**。2 个隐藏关自成一组列在最后（详见下方「隐藏关」）。
  - **难度严格递增**：关卡难度随序号单调递增，无随机或平台期。
  - **内容完全确定性**：42 关（40 常规 + 2 隐藏）由固定种子确定性生成，所有玩家看到**完全一致**的波次序列与关卡内容，无任何随机性/用户间差异；数值由 `test/fixtures/campaign-v1.11.json` 基线快照**逐字段锁定**（若内容意外变动即断言失败），并有「逐关难度与波数不低于 v1.10」的方向性断言。基线快照的生成脚本已随仓库提供（`node test/fixtures/generate.js`），未来真需重校准时可一行复现。
  - **关卡数值由基线锁定，且本次新增内容未再改动它**：结局文案 / 成就 / 榜单 / 统计都不影响闯关平衡，唯一被重写节奏的是**无尽模式**（见上）；因此 `test/fixtures/campaign-v1.11.json` 的 42 关逐字段断言原样通过，作为「关卡数值未被后续改动」的证据。
  - **强度已按新系统重校准**：v1.9 起逐关上调波数、来袭速度与质量；**v1.11 因新增星体专精与布局协同再次重校准**（玩家可用更强的手段，故来袭同步变强）——前三章：波数 9→27、血量 30→18、星能 620→360、难度 0.50→1.55；**第四章延续上升**：波数 27→30、血量 18→16、星能 360→300、难度 1.58→2.03、彗星占比 0.46→0.52，并向所有关卡叠加「强度系数」（前 30 关 1.00→1.12、第四章 1.18→1.26，作用于来袭速度与质量）。
  - **解锁制**：只有通关当前关，才能开启下一关；**第四章另需累计星星达标**（40 关满星 120，门槛 40 星）。前三章 30 关的解锁语义与可达性不因星数改变，避免进度倒退。
  - **星级评价**：每关按表现给 **1~3 星**——★1 通关；★2 通关且母星受击不超过阈值（阈值 = max(2, 波数 × 0.5)，按关卡自适应以保证可达）；★3 通关且**零受击**。失败不计星；每关只保留**本机历史最佳**星数（只增不减）。菜单显示「总星数 / 120」，关卡卡片显示该关星点。
- **隐藏关（2 关，不计星）**：菜单在全部章节之后单独列出「隐藏关」分组——**隐藏关 · 无声围城**（初始星能减半 + 不发放任何道具，共 21 波）与**隐藏关 · 双倍绝境**（来袭速度 ×1.5 + 禁黑洞 + 禁回收升级，共 25 波）。解锁条件分别是**累计星数 ≥ 100** 与**40 个常规关的额外任务全部达成**（卡片上直接显示进度，如「累计星数 96/100」）。两关母星血量极低（12 / 10 点），**不计星、不推进常规解锁进度、不参与满星上限**（满星恒为 120），只记录通关与最佳成绩。两关通关时各有**专属结语**（第二关为真结局）。
  - **旧进度迁移**：老存档只记录「已通关到第几关」，首次运行会自动按「每关 1 星」补齐，不让老玩家倒退。
  - **成就记录**：通关进度、星级与成就记录均存于本机 localStorage。
- **挑战模式**：**与闯关同样的 40 关**，但每关按关卡序号**确定性挂载递增的修饰符**（每 6 关增加一条，最多 5 条），构成"从能打到打不动"的难度梯度。修饰符：**禁道具**（本局不发放道具）→ **来袭加速**（所有威胁速度 ×1.5）→ **星能减半** → **禁黑洞** → **禁回收升级**（并列显示在关卡卡片上）。挑战有**独立的进度与挑战星**（不并入闯关星级与解锁判定），菜单显示「挑战已通关 N 关」。
- **每日挑战**：由**本机日期**派生种子的**固定关卡**（每天一变：波次、强度、星域、修饰符、额外任务都不同），当日**最高分与最高波数**记入本机；跨日自动刷新（**改系统时间即视为新的一天**）。菜单与模式卡上直接显示今日状态（未挑战 / 最高分 / 已通关）。

五种模式均显示**本机最高战绩**（生存分数 / 闯关通关进度 / 无尽最高波数 / 挑战进度 / 当日最高分），存于 localStorage。

### 关卡目标与结算

- 每关开局顶部横幅明确展示**本关目标**（如「守住母星，击退全部 12 波来袭威胁」）、**额外任务**与**失败条件**（如「母星生命值归零」），章首关还会先显示一句剧情文案；数秒后自动淡出，不遮挡核心游玩区。
- 关卡内 HUD **常驻显示当前进度**：固定波次模式（闯关/挑战/每日）显示「当前波/总波」，生存模式显示剩余时间与母星血量，无尽模式显示「第 N 波 · 阶段 M · 距风暴 X 波」。
- HUD 右侧的**下一波来袭预告**显示下一波的构成与来向（如「陨石 ×8 · 彗星 ×3 · 左/右」），Boss 波整条转红并标注 BOSS；生存与无尽模式没有预定波次，该项自动隐藏。无尽模式在该位置显示**阶段胶囊**（阶段 N · 距风暴 X 波，风暴波转红）。
- 达成目标（清空全部波次 / 存活至时间结束）或失败（母星生命归零）时**立即弹出结算面板**，标题与副标题说明成功或失败原因；面板同时展示**额外任务结果**、**本关最佳纪录对比**（新纪录会高亮提示）、**结局文案**（仅闯关第 40 关与两个隐藏关通关时）与**历史榜单名次**（进各模式前 5 名时才提示）；胜利后提供**「下一关」**（闯关/挑战模式自动解锁）与「再来一局」「返回菜单」选项。

**每局都从零开始**：开局场上只有母星，所有星体由你自行摆放（不存在预设布防或上一局布局的自动恢复）。

> 生存模式：每次开局随机生成波次，难度随波次平滑提升且波动受限。闯关模式：波次完全确定性（固定种子），所有玩家一致。

## 玩法

- 陨石从四周来袭，走真实 N 体引力轨道；撞上母星**扣 1 点血**，归零即失败（HUD 同时显示剩余血量数字与血条）。**只有来袭威胁会造成伤害**：你自己放置的星体被引力拽向母星时只会被母星吸收（损失该星体），不会扣血。
- 在下方**星体栏选择档位**，再在空白处**点击**摆放对应星体（成本 = 质量，星能不足或离母星太近会提示）。**场上星体数量上限 60**（物理模拟为 O(N²)，达到上限会提示）。
- 两种轨迹线（均为未来 6 秒、每 2 秒一段共三段、越远越细，可独立开关）：
  - **预测线**：拖拽摆放时预览新星体的轨迹
  - **提示线**：场上运动星体的未来轨迹
  - 颜色含义：🔵 蓝 = 安全 / 引力弹弓　🔴 红 = 将撞母星或被阻挡　🟢 绿 = 将被黑洞吞噬（得分机会）
- 任何星体（含你放置的）**触碰屏幕边界即消失**。
- 来袭威胁若被引力长期拘禁（既不出界也不撞母星），单波超过 **40 秒**会被判定为「已被引力收编」并结算清场，避免卡关。
- **慢动作（0.25×）是有限资源**：每局开局 **15 秒额度**，减速期间按真实时间消耗（按钮实时显示剩余额度，低于 25% 转琥珀色）；**额度耗尽自动恢复常速并提示**，**每清空一波返还 3 秒**（封顶 15 秒）。慢动作因此是「关键波次的手段」，而非常开状态。
- **撞母星预警**：对**未来 6 秒内将撞击母星**的来袭威胁，在威胁本体外显示红色脉动光环与撞击倒计时（如 `2.4s`），并以红虚线指向母星；只预警**来袭威胁**（自己放置的星体撞上母星不扣血，故不预警）。可用「预警」开关关闭。
- **撤销最近放置**：误投可救——点击「撤销」按钮或按 `Z` 键，撤销**最近一次、在 5 秒（游戏时间）内且仍在场上**的星体并**全额返还星能**；已被母星吸收、被黑洞吞噬或飞出边界后不可撤销。
- **星体回收与升级**：**点击**场上星体即可选中（冷蓝光环）并弹出操作面板——「升级」就地升一档（小行星→中行星→大行星→恒星，补差价、位置与初速不变，黑洞不可升级）；「回收」返还该档位成本的 **70%**（按 `Esc` 或「关闭」取消选中）。与「撤销」的区别：撤销＝放置后 5 秒内的**全额纠错**，回收＝任意时刻的**战术腾挪**（有 30% 损耗）。
- **主题场景机关**：6 种星域各有真实机关——宁静星域空场；双星轨道 / 双子恒星生成**伴星**；深井引力生成**引力井**；乱流迷宫散布**固定障碍**；风暴核心生成**脉冲源**。场景天体只参与引力与碰撞（撞上它的来袭威胁会被撞毁，但也会挡住你自己放的星体），**不可点选、回收或升级**，也不计入威胁与波次结算。
- **Boss 关**：每 5 关的收尾波出现一个**需要多段摧毁的巨型天体**（3~5 段）：每次被星体撞击或被黑洞吞噬扣 1 段（有 0.4 秒受伤冷却），段数归零才算清除并给高分；一旦撞上母星会**扣 2 点血**并自身消失（重罚，但不会一击必杀）。顶部中央显示分段血条。
- **新威胁类型**：**分裂彗星**（被拦截或被吞噬后裂成 2 个子体；撞母星不分裂，子体不再分裂）与**引力干扰体**（周期性向外推挤附近天体，逼你调整布防）。
- **一次性道具（纯引力/空间机制，无武器）**：**引力脉冲**（临时强引力井吸附偏转，3 秒后消失）、**斥力波**（把附近来袭威胁推离母星）、**凝滞**（短时全局减速且**不消耗减速额度**）。获取：固定波次模式（闯关/挑战/每日）按关卡发放固定配额（2/1/1）；生存与无尽开局 1/1/1，之后每清 5 波补 1 个（单个上限 3）。选中道具后点击画布释放（带影响半径预览），`Esc` 取消。
- **每关额外任务（只判不罚）**：每关附带一条**确定性附加目标**（不使用任何道具 / 不使用时间减速 / 不放置黑洞 / 不回收不升级 / 通关时星能结余不少于初始预算的一半 / 母星零受击）。达成只在结算面板与关卡卡片上留下**金标记**，**不改变星级、不返还星能**，因此不影响任何一关的既有难度与可达性。菜单显示累计完成的任务数。
- **挑战修饰符会真实生效**：挑战模式的修饰符不是文案——「禁道具」本局道具数为 0、「星能减半」初始星能减半（关卡卡片同步显示减半后的数值）、「来袭加速」所有威胁速度 ×1.5、「禁黑洞」「禁回收升级」「禁减速」在对应操作入口直接拒绝并给出原因。
- **每关最佳记录**：每个模式、每一关都记录**最佳分数 / 最少受击 / 最快通关用时**（只择优、不回退），关卡卡片直接可读，结算面板会提示本次是否刷新纪录。
- **撞毁也计分**：被你的星体或场景机关撞毁的来袭威胁同样计入「拦截威胁清除」（此前只有飞出边界 / 被黑洞吞噬 / 超时收编才计分）。
- **设置会记住**：预测线、撞母星预警的开关状态保存在本机（刷新页面或重开游戏后保持）；「清除进度」/「一键清除进度」会一并复位为默认。
- 背景中淡色**流线箭头**实时可视化引力场方向（越靠近大质量天体越密、越亮），辅助判断如何布防。

## 星体

在下方星体栏选择档位后，点击空白处放置（成本 = 质量，星能不足或离母星太近会提示）：

| 档位 | 质量 / 花费 | 玩法 |
|---|---|---|
| 小行星 | 50 | 弱引力，便宜，微调轨道 |
| 中行星 | 150 | 中等引力，批量布防 |
| 大行星 | 300 | 主力控场，明显引偏来袭天体 |
| 恒星 | 500 | 强引力，大范围捕获 |
| 黑洞 | 1500 | 极强引力·吞噬一切撞来天体，放置后 10 秒（游戏时间）自动消失，谨慎使用（贵） |

固定天体：

| 类型 | 质量 | 玩法 |
|---|---|---|
| 母星 | 8000 | 守护目标，固定 |
| 黑洞（玩家放置） | 1500 | 纯引力·静止，吞噬一切撞来天体，10 秒（游戏时间，慢动作下按比例延长）后自动消失（母星旁有禁放区） |

> 玩家放置的星体与黑洞都**可回收**（返还成本的 70%）；**升级**只适用于「小行星→中行星→大行星→恒星」这条链，黑洞不参与升级。母星不可回收、不可升级。

## 星体专精（v1.11）

同一个档位可以走两条不同的路线——**同样的星能，买到的不是同一种东西**：

| 专精 | 质量 | 半径（碰撞面） | 价格 | 定位 |
|---|---|---|---|---|
| **引力型**（默认） | ×1.00 | ×1.00 | ×1.00（与基础价一致） | 标准引力与价格，最通用的控轨选择 |
| **巨型** | ×0.80 | ×1.50 | ×1.20 | 碰撞面大 50%（每星能约 1.9 倍拦截面积），但引力更弱、更贵 |

- 在星体栏的「专精」切换按钮选择，按钮右侧实时显示该档位在**当前专精**下的「质量 · 半径 · 价格」；拖拽预览与预测线立即按新参数绘制。
- **放置与升级都沿用当前专精**；已放置的星体可在操作面板**同档互转专精**（按差价补/退星能，例如大行星「引力型→巨型」补 60）。
- 黑洞不参与专精（保持 1500 星能、11 半径）。

## 布局协同（v1.11）

**相邻的星体彼此增强引力**——摆放位置本身开始产生数值收益：

- 两颗玩家星体相距 **150px 以内**时，双方**各 +5% 引力质量**；邻近星体越多加成越高，**最高 +30%**。
- 星体若靠近**场景机关**（伴星 / 引力井 / 脉冲源，**120px 以内**）再 **+10%**（障碍是实体墙，不提供引力加成）。
- 两段相加后**总上限 +40%**；选中星体时画面上会显示协同范围圈与当前加成（如 `协同 +15%`）。
- 加成在**物理积分器内部**生效，因此**预测线、引力场流线、计分用的实际引力完全一致**——不会出现"预览不含协同、实战却含"的分歧。

## 得分

清掉来袭威胁按「类型 × 难度加权 × 关卡加权」加分（陨石/彗星之外，Boss 远高于普通威胁，分裂子体最低），清波另有波次奖励，母星受击扣分；最终成绩 = 累计总分（结算面板逐项展示计分规则与明细）。
- **分数一律为整数**：得分、最佳战绩、结算总分均取整存储与显示，杜绝浮点漂移（如 `274.03…`）。
- 生存模式：无限星能，比拼累计分数。
- 闯关模式：有限星能，比拼通关进度；关卡越深关卡倍率越高。
- 挑战与每日挑战：同样按上述规则计分，但**不计关卡倍率**（模式倍率 ×1），成绩分别记入挑战存档与当日存档，互不干扰。

## 成就（本机）

**26 项**成就，解锁瞬间在**结算面板**提示，菜单可展开「成就」面板查看进度：

- 通关与星级：初次告捷（首次通关）、铜墙铁壁（零受击通关）、浴火重生（受击 5 次以上仍通关）、波次机器（击退 15 波以上通关）、群星闪耀（30 星）、星河为证（60 星）、完美星域（集齐全部 120 星）
- 操作类：拦截专家（单局拦截 50）、黑洞胃王（单局黑洞吞噬 10）、从容不迫（不用慢动作通关）、一次成型（通关不回收不升级）、机械师（单局 5 次升级）
- 经济与分数：零浪费（闯关通关且星能结余 ≥ 200）、长明者（生存单局 ≥ 500 分）
- 星体专精：巨石匠（单局放置 5 颗「巨型」）、变形者（单局专精互转 3 次）
- 布局协同：引力共振（单局某颗星体协同加成达 30%）、满格共振（打满 40% 总上限）
- 每日挑战：今日之星（首次通关）、三日不辍（连续通关 3 天）
- 隐藏关：密道探索者（通关任意隐藏关）、星图尽头（两处隐藏关全通关）
- 任务与收集：使命必达（完成全部 40 个常规关的额外任务）、完美星图（120 星 + 40 任务 + 2 隐藏关全清）
- 模式与阶段：风暴幸存者（无尽模式坚守 30 波，历经三次风暴）、挑战者（挑战模式通关 10 关）

成就判定只读取本局结算统计（受击、清除数、星能结余、减速时长、升级/回收次数、黑洞吞噬数、巨型专精放置数、协同加成、无尽波数）或本机存档派生值（累计星数、任务完成数、隐藏关通关数、挑战进度、每日连胜），与界面解耦；重复达成不会重复提示，旧存档中的未知 id 被忽略、已知 id 一律保留（不丢进度）。

## 结局文案（v1.11）

极简叙事收束，只在**结算面板内**展示一段文案，不引入新界面：

- **第四章结局**：通关第 40 关（终焉双源）时展示「结局 · 星海终局」。
- **隐藏关结语**：通关隐藏关 1 展示「结局 · 无声围城」；通关隐藏关 2 展示「真结局 · 双倍绝境」。
- **挑战与每日模式不播剧情**：它们复用同一批关卡，重复讲同一段剧情会弱化收束感，因此结局只属于闯关模式；失败结算也不播。
- 文案写在章节数据（`CHAPTERS[3].ending`）与内容层的独立导出（`window.STORY`）中，**不写进关卡对象**——关卡对象有基线快照的逐字段断言，写入任何新字段都会击穿它。

## 星图总览 / 统计 / 历史榜单（v1.11）

菜单在成就面板下方新增可折叠的「星图总览」，一屏看净三块内容：

1. **收集进度**：闯关星数（含 3★ / 2★ / 1★ / 未通关分布）、额外任务、隐藏关解锁与通关、挑战进度与挑战星、每日挑战（今日状态 / 连胜天数 / 累计通关天数）、成就数。
2. **统计摘要**：累计游戏时长、累计拦截威胁、累计母星受击、累计场次与胜场（含总胜率）、历史最高分与最高波数，以及各模式分别的场次 / 胜场 / 胜率。
3. **历史榜单**：**各模式前 5 名**（生存 / 闯关 / 挑战 / 无尽 / 每日），条目含分数、波数、关卡名与日期；**无尽榜按波数优先排序**（同波数比分数），其余模式按**分数优先**排序。

- 收集度达到 **100%**（120 星 + 40 项额外任务 + 2 个隐藏关全通关）时，面板顶部显示「完美星图」收束文案。
- 结算时若本局进入某模式前 5 名，结算面板提示「进入 XX 榜第 N 名」；未上榜不提示（避免"人人上榜"的廉价感）。
- 统计与榜单只在本机累加，结算时一次写入：失败与通关都计入「场次」，「胜场」只计通关；存储不可用或数据损坏时回退为空并给出提示，不影响结算流程。

## 技术

| 模块 | 职责 |
|---|---|
| `js/physics.js` | 万有引力全 N 体模拟（Verlet 辛积分）、碰撞、`fieldAt` 引力场查询；**天体类型分类的单一真源**（`isThreat/isScene/isPickable`）与多段血量/实心体/周期脉冲/限时回收语义；**星体专精（`SPECS`/`applySpec`）与布局协同（`recomputeSynergy`，每步写回 `body.mass`）的物理唯一真源** |
| `js/predictor.js` | 整系统前向模拟预测轨迹；与其它天体未来位置同步做碰撞判色与截断 |
| `js/render.js` / `js/predictorRenderer.js` | Canvas 渲染、三色分段预测线、引力场流线、HUD、飘字 |
| `js/game.js` | 规则层：模式单一真源（`isFixedWaveMode`）、挑战修饰符拦截点、每关额外任务判定、星级/成就/每日连胜、**无尽阶段与风暴波**（`ENDLESS_STAGES`）、**历史榜单与累计统计**（`starshield_stats` 读写与择优）、结局文案判定（`getRunEnding`）、HUD 与结算数据 |
| `js/input.js` | 拖拽放置与点选星体（升级 / 切换专精 / 回收面板 / `Esc`）、**专精选择器**、模式与开局菜单（5 种模式 + 章节分组 + 隐藏关分组 + 修饰符标签 + 任务徽章 + 最佳记录 + 解锁进度）、减速额度、撤销（按钮/`Z`）、道具槽与释放、Boss 血条、下一波预告、预警与提示线开关、星级与成就展示、**「星图总览」面板（收集进度 / 统计摘要 / 历史榜单）**、结算面板的**结局文案与上榜名次**、音效开关 |
| `js/levels-campaign.js` | 40 关确定性配置（固定种子）：星域主题与场景机关、章节与剧情文案、**第四章结局（`CHAPTERS[3].ending`）与结局文案导出（`window.STORY`：隐藏关结语 / 完美星图）**、每关额外任务、每日挑战生成器（`makeDailyChallenge`） |
| `js/audio.js` | Web Audio 合成音效 |
| `test/run-all.js` | 统一测试入口（语法检查 + 全部测试套件），`npm test`；GitHub Actions 在每次 push/PR 自动执行 |

存档键（均为本机 localStorage）：`starshield_best_score` / `starshield_best_waves` / `starshield_campaign_unlocked`（战绩与进度）、`starshield_stars`（每关最佳星数）、`starshield_achievements`（成就）、`starshield_settings`（预测线与预警开关）、`starshield_audio`（音效开关）、`starshield_challenge`（挑战进度与挑战星）、`starshield_daily`（当日挑战成绩 + 连胜元数据）、`starshield_tasks`（额外任务完成记录）、`starshield_records`（各模式每关最佳记录）、`starshield_stats`（**各模式前 5 的历史榜单 + 累计统计**）。

> 存档读取全部容错：损坏或字段缺失时回退默认值并给出可读提示，不会打断开局或结算。基线快照 `test/fixtures/campaign-v1.10.json` / `campaign-v1.11.json` 与生成脚本 `test/fixtures/generate.js` 属于开发资产，不参与运行时读取。

# 星盾防线 / Star Shield（v1.9）

真实引力物理防守游戏：不能用武器，只能摆放**有质量的真实星体**，用万有引力把来袭陨石**引偏、撞毁或收编**，守护中心母星。

> 版本更新内容见 [Releases](../../releases) 与 git 提交记录。

## 运行

双击 `index.html` 即可游玩。纯前端、零依赖、全程离线。

开发：`npm test` 运行「语法检查 + 全部测试套件」（零依赖，仅需 Node ≥ 18）。

> **纯单机**：无账号、无云存档、无在线排行榜，也不发起任何网络请求。全部进度（战绩、解锁、星级、成就、设置）只保存在本机 `localStorage`（键名前缀 `starshield_`），「清除进度」会一并删除。

## 模式

开局菜单选择：

- **生存模式**：无限星能、限时来袭，比拼**累计分数**（活得越久、清得越多分越高）。波次仅用于内部难度递增，不计入成绩。
- **无尽模式**：无限波次、无时间限制，难度在封顶后仍会**缓慢上升**；比拼**最高波数**（同时记录累计分数）。本机记录显示为「无尽最高 N 波」。
- **闯关模式**：固定星能、**30 关层层递进**，比拼**通关进度**。母星血量随关卡递减、星能收紧、波次增多、来袭速度与质量提升、彗星占比上升。每关关卡卡片均展示**简介**（场景特色与挑战）。
  - **章节结构**：30 关分为 3 章（第一章 星域初探 / 第二章 引力深井 / 第三章 风暴核心），菜单按章分组并显示该章星数完成度。
  - **难度严格递增**：关卡难度随序号单调递增，无随机或平台期。
  - **内容完全确定性**：30 关由固定种子确定性生成，所有玩家看到**完全一致**的波次序列与关卡内容，无任何随机性/用户间差异。
  - **强度已按新系统重校准**：因 v1.8 加入「回收 70% 返还 + 就地升级」使难度下降，v1.9 起逐关上调了波数、来袭速度与质量，并相应调整血量/星能（波数 9→26、血量 30→20、星能 620→370、难度 0.50→1.45）。
  - **解锁制**：只有通关当前关，才能开启下一关（星数**不**用于锁关，避免既有进度倒退）。
  - **星级评价**：每关按表现给 **1~3 星**——★1 通关；★2 通关且母星受击不超过阈值（阈值 = max(2, 波数 × 0.5)，按关卡自适应以保证可达）；★3 通关且**零受击**。失败不计星；每关只保留**本机历史最佳**星数（只增不减）。菜单显示「总星数 / 90」，关卡卡片显示该关星点。
  - **旧进度迁移**：老存档只记录「已通关到第几关」，首次运行会自动按「每关 1 星」补齐，不让老玩家倒退。
  - **成就记录**：通关进度、星级与成就记录均存于本机 localStorage。

两种模式均显示**本机最高战绩**（生存分数 / 闯关通关进度），存于 localStorage。

### 关卡目标与结算

- 每关开局顶部横幅明确展示**本关目标**（如「守住母星，击退全部 12 波来袭威胁」）与**失败条件**（如「母星生命值归零」），数秒后自动淡出，不遮挡核心游玩区。
- 关卡内 HUD **常驻显示当前进度**：闯关模式显示「当前波/总波」，生存模式显示剩余时间与母星血量。
- 达成目标（清空全部波次 / 存活至时间结束）或失败（母星生命归零）时**立即弹出结算面板**，标题与副标题说明成功或失败原因；胜利后提供**「下一关」**（闯关模式自动解锁）与「再来一局」「返回菜单」选项。

**每局都从零开始**：开局场上只有母星，所有星体由你自行摆放（不存在预设布防或上一局布局的自动恢复）。

> 生存模式：每次开局随机生成波次，难度随波次平滑提升且波动受限。闯关模式：波次完全确定性（固定种子），所有玩家一致。

## 玩法

- 陨石从四周来袭，走真实 N 体引力轨道；撞上母星**扣 1 点血**，归零即失败（HUD 同时显示剩余血量数字与血条）。**只有来袭威胁会造成伤害**：你自己放置的星体被引力拽向母星时只会被母星吸收（损失该星体），不会扣血。
- 在下方**星体栏选择档位**，再在空白处**点击**摆放对应星体（成本 = 质量，星能不足或离母星太近会提示）。**场上星体数量上限 60**（物理模拟为 O(N²)，达到上限会提示）。
- 两种轨迹线（均为未来 6 秒、每 2 秒一段共三段、越远越细，可独立开关）：
  - **预测线**：拖拽摆放时预览新星体的轨迹
  - **提示线**：场上运动星体的未来轨迹
  - 颜色含义：🔵 蓝 = 安全 / 引力弹弓　🔴 红 = 将撞母星或被阻挡　🟢 绿 = 将被黑洞吞噬（得分机会）
- 任何星体（含你放置的）**触碰屏幕边界即消失**。
- 来袭威胁若被引力长期拘禁（既不出界也不撞母星），单波超过 **40 秒**会被判定为「已被引力收编」并结算清场，避免卡关。
- **慢动作（0.25×）是有限资源**：每局开局 **15 秒额度**，减速期间按真实时间消耗（按钮实时显示剩余额度，低于 25% 转琥珀色）；**额度耗尽自动恢复常速并提示**，**每清空一波返还 3 秒**（封顶 15 秒）。慢动作因此是「关键波次的手段」，而非常开状态。
- **撞母星预警**：对**未来 6 秒内将撞击母星**的来袭威胁，在威胁本体外显示红色脉动光环与撞击倒计时（如 `2.4s`），并以红虚线指向母星；只预警**来袭威胁**（自己放置的星体撞上母星不扣血，故不预警）。可用「预警」开关关闭。
- **撤销最近放置**：误投可救——点击「撤销」按钮或按 `Z` 键，撤销**最近一次、在 5 秒（游戏时间）内且仍在场上**的星体并**全额返还星能**；已被母星吸收、被黑洞吞噬或飞出边界后不可撤销。
- **星体回收与升级**：**点击**场上星体即可选中（冷蓝光环）并弹出操作面板——「升级」就地升一档（小行星→中行星→大行星→恒星，补差价、位置与初速不变，黑洞不可升级）；「回收」返还该档位成本的 **70%**（按 `Esc` 或「关闭」取消选中）。与「撤销」的区别：撤销＝放置后 5 秒内的**全额纠错**，回收＝任意时刻的**战术腾挪**（有 30% 损耗）。
- **主题场景机关**：6 种星域各有真实机关——宁静星域空场；双星轨道 / 双子恒星生成**伴星**；深井引力生成**引力井**；乱流迷宫散布**固定障碍**；风暴核心生成**脉冲源**。场景天体只参与引力与碰撞（撞上它的来袭威胁会被撞毁，但也会挡住你自己放的星体），**不可点选、回收或升级**，也不计入威胁与波次结算。
- **Boss 关**：每 5 关的收尾波出现一个**需要多段摧毁的巨型天体**（3~5 段）：每次被星体撞击或被黑洞吞噬扣 1 段（有 0.4 秒受伤冷却），段数归零才算清除并给高分；一旦撞上母星会**扣 2 点血**并自身消失（重罚，但不会一击必杀）。顶部中央显示分段血条。
- **新威胁类型**：**分裂彗星**（被拦截或被吞噬后裂成 2 个子体；撞母星不分裂，子体不再分裂）与**引力干扰体**（周期性向外推挤附近天体，逼你调整布防）。
- **一次性道具（纯引力/空间机制，无武器）**：**引力脉冲**（临时强引力井吸附偏转，3 秒后消失）、**斥力波**（把附近来袭威胁推离母星）、**凝滞**（短时全局减速且**不消耗减速额度**）。获取：闯关按关卡发放固定配额（2/1/1）；生存与无尽开局 1/1/1，之后每清 5 波补 1 个（单个上限 3）。选中道具后点击画布释放（带影响半径预览），`Esc` 取消。
- **撞毁也计分**：被你的星体或场景机关撞毁的来袭威胁同样计入「拦截威胁清除」（此前只有飞出边界 / 被黑洞吞噬 / 超时收编才计分）。
- **设置会记住**：预测线、撞母星预警的开关状态保存在本机（刷新页面或重开游戏后保持）；「清除进度」/「一键清除进度」会一并复位为默认。
- 背景中淡色**流线箭头**实时可视化引力场方向（越靠近大质量天体越密、越亮），辅助判断如何布防。

## 星体

在下方星体栏选择档位后，点击空白处放置（成本 = 质量，星能不足或离母星太近会提示）：

| 档位 | 质量 / 花费 | 玩法 |
|---|---|---|
| 小行星 | 50 | 弱引力，便宜，微调轨道 |
| 中行星 | 150 | 中等引力，批量布防 |
| 大行星 | 300 | 主力控场，明显引偏来袭天体 |
| 恒星 | 500 | 强引力，大范围捕获 |
| 黑洞 | 1500 | 极强引力·吞噬一切撞来天体，放置后 10 秒（游戏时间）自动消失，谨慎使用（贵） |

固定天体：

| 类型 | 质量 | 玩法 |
|---|---|---|
| 母星 | 8000 | 守护目标，固定 |
| 黑洞（玩家放置） | 1500 | 纯引力·静止，吞噬一切撞来天体，10 秒（游戏时间，慢动作下按比例延长）后自动消失（母星旁有禁放区） |

> 玩家放置的星体与黑洞都**可回收**（返还成本的 70%）；**升级**只适用于「小行星→中行星→大行星→恒星」这条链，黑洞不参与升级。母星不可回收、不可升级。

## 得分

清掉来袭威胁按「类型 × 难度加权 × 关卡加权」加分（陨石/彗星之外，Boss 远高于普通威胁，分裂子体最低），清波另有波次奖励，母星受击扣分；最终成绩 = 累计总分（结算面板逐项展示计分规则与明细）。
- **分数一律为整数**：得分、最佳战绩、结算总分均取整存储与显示，杜绝浮点漂移（如 `274.03…`）。
- 生存模式：无限星能，比拼累计分数。
- 闯关模式：有限星能，比拼通关进度；关卡越深关卡倍率越高。

## 成就（本机）

14 项成就，解锁瞬间在**结算面板**提示，菜单底部可展开「成就」面板查看进度：

- 通关类：初次告捷（首次通关）、铜墙铁壁（零受击通关）、浴火重生（受击 5 次以上仍通关）、波次机器（击退 15 波以上通关）
- 星级类：群星闪耀（30 星）、星河为证（60 星）、完美星域（集齐 90 星）
- 操作类：拦截专家（单局拦截 50）、黑洞胃王（单局黑洞吞噬 10）、从容不迫（不用慢动作通关）、一次成型（通关不回收不升级）、机械师（单局 5 次升级）
- 经济与分数：零浪费（闯关通关且星能结余 ≥ 200）、长明者（生存单局 ≥ 500 分）

成就判定只读取本局结算统计（受击、清除数、星能结余、减速时长、升级/回收次数、黑洞吞噬数），与界面解耦；重复达成不会重复提示。

## 技术

| 模块 | 职责 |
|---|---|
| `js/physics.js` | 万有引力全 N 体模拟（Verlet 辛积分）、碰撞、`fieldAt` 引力场查询；**天体类型分类的单一真源**（`isThreat/isScene/isPickable`）与多段血量/实心体/周期脉冲/限时回收语义 |
| `js/predictor.js` | 整系统前向模拟预测轨迹；与其它天体未来位置同步做碰撞判色与截断 |
| `js/render.js` / `js/predictorRenderer.js` | Canvas 渲染、三色分段预测线、引力场流线、HUD、飘字 |
| `js/input.js` | 拖拽放置与点选星体（升级/回收面板/`Esc`）、模式与开局菜单（含无尽模式与章节分组）、减速额度、撤销（按钮/`Z`）、道具槽与释放、Boss 血条、预警与提示线开关、星级与成就展示、音效开关 |
| `js/audio.js` | Web Audio 合成音效 |
| `test/run-all.js` | 统一测试入口（语法检查 + 全部测试套件），`npm test`；GitHub Actions 在每次 push/PR 自动执行 |

存档键（均为本机 localStorage）：`starshield_best_score` / `starshield_best_waves` / `starshield_campaign_unlocked`（战绩与进度）、`starshield_stars`（每关最佳星数）、`starshield_achievements`（成就）、`starshield_settings`（预测线与预警开关）、`starshield_audio`（音效开关）。

# 星盾防线 / Star Shield（v1.3）

真实引力物理防守游戏：不能用武器，只能摆放**有质量的真实星体**（小行星 / 恒星 / 黑洞），用万有引力把来袭陨石**引偏、撞毁或收编**，守护中心母星。

> 版本更新内容见 [Releases](../../releases) 与 git 提交记录。

## 运行

双击 `index.html` 即可游玩。纯前端、零依赖、全程离线。

## 玩法

- 陨石从四周来袭，走真实 N 体引力轨道；撞上母星扣血。
- 在空白处**按住拖拽**摆放星体：拖拽方向 = 初速方向，长度 = 初速大小（1px = 0.5 m/s）。
- 两种轨迹线（均为未来 6 秒、每 2 秒一段共三段、越远越细，可独立开关）：
  - **预测线**：拖拽摆放时预览新星体的轨迹
  - **提示线**：场上运动星体的未来轨迹
  - 颜色含义：🔵 蓝 = 安全 / 引力弹弓　🔴 红 = 将撞母星或被阻挡　🟢 绿 = 将被黑洞吞噬（得分机会）
- 任何星体（含你放置的）**触碰屏幕边界即消失**。
- 可随时点击「时间：正常 / 减速」切换**慢动作（0.25×）**，时间变慢但不停止，从容布防。

## 星体档位

| 类型 | 质量 | 花费 | 玩法 |
|---|---|---|---|
| 小行星 | 50 | 3 | 便宜，成排拦截 |
| 中行星 | 200 | 6 | 撞击为主 |
| 大行星 | 600 | 12 | 撞击 + 引力 |
| 恒星 | 1500 | 20 | 强引力控场 |
| 黑洞 | 6000 | 30 | 纯引力·静止·限时 12s，吞噬一切撞来天体（母星旁有禁放区） |

## 得分

撞击炸毁 **+25** ｜ 黑洞吞噬 **+20** ｜ 安全飞出 **+8** ｜ 母星受击 **−12 血**。
最终得分 = 累计得分 − 建造花费。最高分本地保存。

## 技术

| 模块 | 职责 |
|---|---|
| `js/physics.js` | 万有引力全 N 体模拟（Verlet 辛积分）、碰撞 |
| `js/predictor.js` | 整系统前向模拟预测轨迹；与其它天体未来位置同步做碰撞判色与截断 |
| `js/render.js` / `js/predictorRenderer.js` | Canvas 渲染、三色分段预测线、HUD、飘字 |
| `js/input.js` | 拖拽放置、档位与预算、时间减速、音效开关、提示线/预测线开关 |
| `js/audio.js` | Web Audio 合成音效 |

### 更新日志

- **v1.3**（2026-08-08）：
  - 移除"暂停"机制，改为「时间减速（0.25×）」：时间变慢但不停止，减速时屏震与提示线仍正常演算，布防时画面连贯无闪烁；仅游戏结束时冻结屏震。
  - 修复减速无效的 bug：物理子步时长此前未乘 `timeScale`，导致只有生成 / 黑洞计时 / 特效变慢、星体实际速度不变；现已让星体、生成、计时、特效整体同步慢下来，减速才真正降低难度。
  - 新增音效开关（「音效：开 / 关」按钮），状态本地持久化。
  - 「重新开始」按钮改为二次确认（点击变红「确认重开？」，3 秒内再点才执行，超时自动还原），并弱化为低调次级按钮，避免游戏进行中误触丢局。

- **v1.2**（2026-08-08）：
  - 分辨率适配：开局前按屏幕宽高比自动确定宇宙尺寸（较短边固定 600，星体视觉大小一致），开局态画布铺满屏幕、无黑边；按设备像素比(DPR)高清渲染。开局后窗口缩放仅做等比"包含"缩放（可能留黑边），以免打乱已摆放星体的比例与平衡。
  - 新增手机触摸屏支持：交互统一改用 Pointer Events（鼠标 / 触摸 / 笔通吃），可手指拖拽摆放星体；`canvas` 加 `touch-action: none` 避免误触滚动。
